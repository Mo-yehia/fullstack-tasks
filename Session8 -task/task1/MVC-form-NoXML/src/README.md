# Spring MVC Form Application

## Overview
- This project is a simple Spring MVC web application that demonstrates how to create and process a form using Spring’s <form:form> tag library.

- It also shows how to configure static resource handling (CSS, JS, etc.) using Java-based configuration with annotations — no XML configuration is used.
 
--- 
### Technologies Used

- Java 17
- Spring MVC
- JSP (Java Server Pages)
- Bootstrap 4
- CSS (custom styling)
- Lombok (for getters/setters)

### Example Output

- Form Page:

  User fills in details with dropdowns, checkboxes, and radio buttons.

- Result Page:

  Displays submitted data neatly inside a card with custom styling.
