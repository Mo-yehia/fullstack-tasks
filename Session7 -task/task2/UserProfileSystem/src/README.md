# User Registration App (Spring MVC + MySQL)

## Overview
This is a simple **Spring MVC** web application that allows users to fill out a registration form and saves their information in a **MySQL database** using **JDBC**.  
After submitting the form, the application displays the entered data on a results page.

---

## Features
- Displays a registration form for the user.
- Saves the user’s information (first name, last name, email, date of birth, and city) into a database.
